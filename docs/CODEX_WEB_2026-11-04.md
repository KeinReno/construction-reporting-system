# Codex CLI в кабинете руководителя — 04.11.2026

Подключение: backend/app/codex_provider.py запускает существующий Codex CLI с текущей авторизацией ChatGPT. Runtime config хранится вне исходников в C:\CRS-Live\config.json (codex.enabled/executable). Отдельный API key не используется.

В Web раздел «Помощник» поддерживает вопросы по выбранной выборке. Передаются вопрос, ограниченная история беседы, серверные агрегаты и каталог доступных отчётов/объектов с локальными ссылками. Исходные документы, фото, пароли, токены CRS и файлы БД не передаются. Свободные текстовые поля вопроса и агрегатов могут содержать введённые пользователем сведения; автоматическая анонимность не гарантируется.

Действия: переименование доступного объекта; проверка или возврат нового submitted отчёта; полный новый комментарий draft/needs_revision. Исторические отчёты, суммы, пользователи и права через чат не меняются. Действие создаёт одноразовое серверное предложение на 10 минут, привязанное к пользователю. Только кнопка «Применить» вызывает сохранение; backend заново проверяет роль, назначение и версию/состояние или прежнее имя. Повторное применение возвращает тот же результат, аудит сохраняется. Перезапуск отменяет ожидающие предложения.

CLI запускается без пользовательского config/rules, в отдельном временном cwd, ephemeral/read-only; shell/apps/plugins/web и другие внешние инструменты отключены. Вход через stdin, JSON schema output, env allowlist, stdout/stderr не сохраняются, timeout 90 секунд с завершением дерева процессов. Запросы CLI сериализованы; квота 20 в день на пользователя хранится в памяти процесса. История Web — в памяти страницы.
