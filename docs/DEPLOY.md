# DEPLOY — Windows-сервер заказчика

## До запуска
Узнать Windows-версию, CPU/RAM, дисковое место, резервное питание, политику обновлений и доступность HTTPS-туннеля в реальных сетях.

## Схема
FastAPI + PostgreSQL + приватное хранилище фотографий + Web UI + TLS reverse proxy. Вариант Windows-служб или поддерживаемого контейнерного окружения определить после осмотра сервера. PostgreSQL слушает только локальный/закрытый интерфейс.

## Настройка
- Передавать секреты только через защищённую конфигурацию (не Git).
- Автозапуск, журнал событий без персональных данных и токенов.
- Ограничить размер запросов и файлов.
- HTTPS-адрес для Android и Web; отсутствие обязательного VPN проверить фактически.
- Раздельные учётные записи и права на БД/фото.
- Резервировать БД и вложения согласованно и хранить копию вне основного сервера.
- Регулярно проверять реальное восстановление; зафиксировать RPO/RTO с заказчиком.
- Обновления — с резервной копией и планом отката.

## Запуск
1. Настроить БД и миграции.
2. Создать администратора безопасным способом.
3. Запустить API и Web.
4. Проверить авторизацию, создание отчёта и загрузку фото.
5. Проверить внешний доступ и роли.
6. Сделать backup/restore тест.
7. Передать короткие инструкции.

Не размещать реальные пароли, IP инфраструктуры клиента и пользовательские данные в этом публичном репозитории.
