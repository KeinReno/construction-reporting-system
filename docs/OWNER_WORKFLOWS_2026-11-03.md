# Кабинет владельца — сценарии и проверка

## Что изменено

- Главная показывает последние указанные работы и события по объектам, а также последние отчёты.
- Карточка объекта разделена на работы и отчёты, фотографии, деньги, материалы и технику. История раскрывается постепенно; из записей можно перейти к исходному отчёту.
- В журнале отчётов есть поиск, фильтры статуса и компактное отображение. На странице отчёта сначала показано содержание и действия проверки, а история изменений доступна отдельно.
- В разделе денег раздельно показаны расходы, поступления и авансы; расходы можно отфильтровать по категории. Период фильтруется по дате операции. В карточке объекта выборка привязана к дате смены отчёта, что указано на экране.
- Аналитика показывает указанные объёмы с единицами и число полученных отчётов по периодам; из показателей доступны исходные записи. Готовые сводки формируются сервером по доступным функциям.

## Границы данных

Фотографии, непосредственно связанные с отчётом, отделены от фотографий, совпадающих только по дате: последняя связь требует проверки. Отсутствие данных не означает подтверждённый ноль; баланс и процент готовности не рассчитываются. Неизвестные объёмы не подменяются выдуманными. Записи и права доступа сервера не менялись; полнота переноса данных в рамках этой задачи не сверялась.

## Проверка

- `cd web && npm run build` — PASS, сборка Web.
- `cd web && npx playwright test --timeout=30000` — 23 PASS, сквозные сценарии на отдельной синтетической базе.
- Независимая проверка на синтетических данных: история объекта, фильтры, источник фото, категории и даты денег, возврат с причиной, реальный конфликт версий 409, переходы к исходным записям, ширины 320/390/1440 px.
- Реальные данные просмотрены локально без изменения. Физический iPhone и доступ через интернет в этой задаче не проверялись.

## Продолжение

Показать владельцу и согласовать, какие решения он должен принимать по данным в каждом разделе. Отдельно проверить полноту и достоверность исходного переноса; согласовать бизнес-правила для баланса, плана и показателей готовности до их добавления.
