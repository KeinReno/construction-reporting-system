# ARCHITECTURE — модульный монолит

## Компоненты
Android (Kotlin/Compose, Room, WorkManager) → HTTPS REST API (FastAPI) → PostgreSQL. Фотографии — приватное файловое хранилище с метаданными и sha256 в БД. Web (React/TypeScript) читает только API. ИИ-аналитик работает через серверные read-only инструменты.

## Поток отчёта
1. Сотрудник заполняет форму и сохраняет запись локально атомарной транзакцией.
2. Стабильный client_report_id создаётся один раз. Отправляется draft; повторный запрос идемпотентен.
3. Фото отправляются отдельно со стабильным attachment_id, sha256 и контролем полной загрузки.
4. Submit завершает отчёт только после валидации всех обязательных данных и вложений.
5. Сервер отвечает подтверждённым статусом; Android отмечает доставку.
6. Руководитель отдельно проверяет или возвращает отчёт. История исправлений не стирается.

## Надёжность
Экспоненциальные повторы, обработка конфликтов версий, лимиты загрузки, атомарность состояния, отсутствие дублей и проверка восстановимости резервных копий. При недоступности сервера черновики остаются локально.

## Безопасность
TLS, авторизация, ограничения по назначенным объектам на каждом endpoint, права на вложения, лог действий. БД не публикуется напрямую. Внешний HTTPS-шлюз выбирается после проверки доступности в целевых сетях, с VPN и без него.

## Даты
work_date — дата работ на объекте; submitted_at — время сервера в UTC; photo_taken_at — необязательная метка EXIF, которой нельзя безусловно доверять.

## Масштабирование и Orion
Единый backend для MVP. Не строить микросервисы. Будущая интеграция Orion — отдельный адаптер через /api/v1 и события экспорта; не допускать смешивания данных организаций.
