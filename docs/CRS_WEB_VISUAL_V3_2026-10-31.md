# CRS Web Visual v3 — исправления по реальным скриншотам от 31.10.2026

## Диагноз по предоставленным изображениям
- Текст на снимках выглядит уменьшенным: ширина sidebar около 170 px против CSS-ширины 224 px; возможно браузерный масштаб около 75%. Проверять на масштабе 100% и при 75%, не выдавать предположение за доказанный факт.
- На главной KPI-ряд в 5 элементов ломался на 4 + 1, оставляя видимую серую пустую площадь. В финансовом разделе и карточке объекта аналогично возникали незаполненные ячейки.
- Существующие поля фильтрации оставляли большие пустые зоны; контент был зажат по центру при широком CSS-viewport.
- Подписи 10–12px при уменьшенном масштабе становились нечитабельными.
- Горизонтальные полосы графика при трёх равных значениях выглядели как одинаковые полные прогрессы; у временного ряда не было собственной визуальной иерархии.
- Блок «Описанные работы» использовал flex-стили для `details`: кнопки источников визуально уезжали и нарушали ритм.
- Отсутствие денег было отражено как большая пустота вместо осмысленного состояния с объяснением.

## Что исправлено
- `design/visual-v3.css`: финальный слой экранной сетки и типографики после `shark-finish.css`, без новых зависимостей.
- Главная: 5 KPI в одну строку на широком экране, 4 на аналитике; без серых пустых ячеек, выделена доставленная отчётность.
- «Деньги»: 3 полноширинных KPI на desktop, отдельный информативный empty-state.
- «Объект»: три денежные характеристики в компактные строки внутри сайдбара, читаемая хронология.
- «Аналитика»: вертикальные столбцы временного ряда, сохраняются реальные данные, клики на первичные отчёты и режим группировки по датам.
- «Описанные работы»: раскрываемые строки вместо сломанной верстки flex; источники во вложенном блоке.
- Полезная ширина веб-приложения не обрезается фиксированным узким max-width; отдельные адаптивные режимы.

## Без изменения
API/backend, Android, значения сумм и отчётов, факт/дата операций, статусы, маршрутизация, функции фильтрации и проверки остаются прежними. Список «нет данных» не интерпретируется как подтверждённый ноль.

## Проверка
```bash
cd web
npm ci
npm run build
npm run test:e2e
```
На локальном ПК проверить 100% и 75% zoom, desktop 1440/1920px и мобильный Web 390px. Проверить непереполнение KPI-сетки, отсутствие горизонтальной прокрутки всей страницы, кликабельность вертикального графика, открытие исходных отчётов и финансовые фильтры.
