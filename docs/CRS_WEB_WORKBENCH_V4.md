# CRS Workbench V4 — новый веб-интерфейс, а не CSS-скин

Новая композиция Web CRS с отдельными JSX-модулями:
- `workbench/WorkbenchChrome.tsx`: верхняя консоль, нумерованный masthead, контрастный ivory command hero, обзор состояния и разделители рабочих зон.
- `workbench/SituationBoardV4.tsx`: новая композиция объекта и очереди проверки.
- `design/workbench-v4.css`: отдельная система продуктового дизайна, переработаны навигация, типографика, цвет, данные и адаптивность.
- `App.tsx`: старая линейная KPI-сетка на Главной заменена новой панелью, выведены секции, навигация подключена к текущим маршрутам.

Это не установка компонентов оригинального Shark UI, а независимая React-реализация с использованием UX-паттернов. Android/backend/API и расчёты сумм/процентов не менялись.

## Приёмка
Проверить: `cd web && npm ci && npm run build && npm run test:e2e`.
Главная 1440/1920px должна существенно отличаться от прежней: светлый командный блок слева, тёмный рабочий обзор справа, индексированная навигация, типографический заголовок и секции, новая очередь проверки и карточки объектов.
Вторая проверка на 390 и 768px. Подтвердить источники отчётов, фильтры, login, отдельный просмотр отчёта и обновление данных.

Отдельная ветка `feat/crs-web-workbench-v4`. До интеграции локальным агентом не удалять старую ветку и не менять рабочую копию через `reset --hard`.
