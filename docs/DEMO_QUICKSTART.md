# СтройКонтроль — демо 0.3.1

## Android
Установите construction-android-demo-0.3.1.apk (Android 8+). Это отдельное приложение «СтройКонтроль Демо» и отдельное хранилище: рабочая версия не заменяется. Откройте — примеры загружены автоматически. Сервер, пароль, VPN и интернет для демо не нужны.

Вверху — пояснение и примеры; ниже — настоящая форма приложения. Откройте карточку примера, посмотрите работы/причину/схему. Добавьте свою работу, сохраните и отправьте: данные останутся только в локальном демо. Фраза «Демо: сохранён» не означает получение отчёта сервером клиента. Можно проверить возвращённый пример и сделать исправление. Выйти → «Открыть демо» восстанавливает вход. После перезапуска пользовательские демо-записи сохраняются. Для полного сброса удалите данные только приложения «СтройКонтроль Демо» в настройках Android.

## Windows 10/11 x64
Полностью распакуйте construction-windows-demo.zip. Запустите Start-Demo.cmd или ConstructionReportingDemo.exe. Python, PostgreSQL и Node устанавливать не нужно. Откроется браузер с реальными Web и API на локальном адресе. Нажмите «Открыть демо: Руководитель» или «Администратор».

В консоли напечатан адрес: если браузер не открылся, скопируйте его. Оставьте консоль открытой. Для остановки закройте консоль или Ctrl+C; закрытие вкладки не останавливает приложение. Повторный запуск сохраняет демо-изменения. Данные находятся в %LOCALAPPDATA%\ConstructionReporting\Demo-0.3.1. Для сброса остановите демо и переименуйте эту папку. Рабочая БД клиента не используется.

Для ручного входа: demo-manager / demo-admin / demo-foreman, пароль Demo-Only-2026!. Эти общедоступные демо-аккаунты никогда не использовать в эксплуатации. APK подписан отладочным ключом, EXE не подписан коммерческим сертификатом: Windows/Android могут показать предупреждение об источнике. Не отключайте защиту устройства.

## Посмотреть за 5 минут
1. Главная → два объекта, график дней и учебный объём 8.5 м.
2. Отчёты → 15–21 мая: покраска, нехватка краски, недопуск, монтаж; карточка → схема и история.
3. Фильтр по объекту и датам; сравните изменения сводки.
4. Откройте доставленный отчёт → «Проверен» либо верните с причиной.
5. ИИ-аналитик → «Какие простои повторяются?» → исходный отчёт. Это локальная аналитика, внешняя модель не подключена.
6. Войдите администратором → Управление: пользователи, объекты, назначения.

## Про данные и ограничения
Шесть записей: пять обезличенных адаптаций части присланных сообщений и один полностью синтетический пример для количественного графика. Имена, компании, маршруты, суммы и исходные фотографии не включены. Даты примеров 15–22.05.2026; статусы проверки учебные. Количественные объёмы исходных сообщений не выдумывались. Иллюстрации — схемы с надписью DEMO/SCHEMATIC, не фото объекта. Это не полный импорт истории, не финансовый учёт и не доказательство фактических показателей заказчика.

Android и Windows в этом комплекте — два независимых локальных демо. Записи между ними не синхронизируются. Проверка настоящей отправки с телефона на Windows требует рабочего HTTPS и обычного APK; runtime и обычный APK находятся в PR #2. Не вводите реальные клиентские данные в демонстрационный контур.
