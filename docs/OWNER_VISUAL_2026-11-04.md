# Визуальная иерархия кабинета владельца

Главная показывает показатели доступных объектов, полученных отчётов и ожидающих проверки; карточки объектов содержат фактические последние записи. Новый график группирует полученные отчёты по дате смены за последние шесть месяцев, в которых есть данные. Выбор месяца показывает исходные отчёты. Он не обозначает объём работ, готовность или выполнение плана.

В обзоре объекта отделены сведения об отчётах, фотографиях, деньгах и событиях; добавлены подписи, иконки и состояния выбранных разделов. Расходы, поступления и авансы остаются раздельными, связи фотографий по одной дате не считаются подтверждёнными, даты событий не скрываются. Переходы при наведении и выборе не используются при системной настройке уменьшения движения.

## Проверка

- `cd web && npm run build` — PASS.
- `cd web && npx playwright test --timeout=30000` — 26 PASS на синтетической БД; добавлены проверки источников месячного графика и непересекающихся подписей за шесть месяцев.
- Независимый QA: сценарии объекта и главной, пустые и ошибочные состояния, клавиатура, фото, деньги, источники, reduced motion и ширины 320/390/768/1440. Найденное переполнение графика исправлено и повторно проверено.
- Установленная локальная версия открыта для просмотра рабочих данных без их изменения. Физический телефон, полнота переноса данных и интернет-доступ не проверялись.

Работа ограничена главной и обзором объекта. Остальные разделы сохраняют прежнее оформление и поведение; их визуальную доработку следует согласовать после просмотра владельцем.
