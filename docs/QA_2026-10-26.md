# QA — 26.10.2026, Android form durability

Ветка `feat/mvp-core-bootstrap`, PR #2. Только синтетические записи. SPEC-00 OPEN без изменений.

## Устранённые риски
- `remember`-форма теряла сырой ввод и ссылки на фото при recreation. Добавлена отдельная Room-форма с owner, session nonce и версией payload.
- Частичная форма не должна попадать в очередь. UI hydration завершает чтение до включения автосейва; хранение формы отдельно от `drafts`.
- Поздний автосейв после сохранения отчёта мог восстановить старую форму. UPDATE-only owner/session и атомарный enqueue/consume исключают повторное создание.
- Ошибка записи очереди не должна удалять форму: тест SQLite-trigger проверяет rollback.
- Исправление другого отчёта могло молча заменить текущую форму. Теперь требуется подтверждение; отмена сохраняет ввод. Повторная отправка failed отключена во время редактирования.
