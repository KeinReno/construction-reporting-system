# Обзор объекта для владельца

## Поведение

Объект открывается на вкладке «Обзор». Последние отчёты содержат дату, фактически указанные работы, бригаду или автора и статус; каждая строка открывает отчёт. Рядом показаны раздельные расход, поступление и аванс из полученных отчётов. Выборка относится к дате смены, которая может отличаться от даты операции. При отсутствии операций отображается «Не указано», остаток не рассчитывается.

События выводятся с датами и ссылками на исходные отчёты: это сообщения из прошлого, а не автоматически установленные текущие проблемы. Подтверждённые фотографии выводятся с переходом к отчёту; совпадающие только по дате отмечены отдельно и требуют проверки. Вкладки работ, фотографий, денег и ресурсов сохранены. Новый экран не меняет API, базу, правила проверки и интерфейс сотрудника.

## Проверка

- `cd web && npm run build` — PASS.
- `cd web && npx playwright test --timeout=30000` — 24 PASS на отдельной синтетической базе; после изменения отступов повторены три сценария объекта — 3 PASS.
- Независимый QA: 17 проверок на синтетических данных, включая раздельные суммы, разные даты операции и смены, источник события, точные и предположительные связи фото, пустые состояния и возврат к фильтру. После изменения отступов дополнительно проверены ширины 320/390/768/1440 px.
- Установленная локальная версия открыта на доступном объекте в режиме просмотра. Рабочая база не изменялась; полнота переноса и физический iPhone не проверялись.
