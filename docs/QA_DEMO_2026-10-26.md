# Демо-комплект 0.3.1 — 26.10.2026

Состав: отдельный APK applicationId com.kaiden.construction.demo; Windows x64 ZIP с ConstructionReportingDemo.exe, Start-Demo.cmd и START_HERE.md; отдельная инструкция для скачивания. Оба демо автономны и не синхронизируются друг с другом. В APK настоящий native UI/Room/Worker с явно локальным симулятором транспорта; EXE содержит реальные Backend/Web, встроенный Python и приватную SQLite. Это не установка PostgreSQL/HTTPS у клиента.

## Найденный и устранённый P1
На Windows Starlette передаёт StaticFiles path как assets\\index.js. Allowlist принимал только assets/ и отдавал404 для JS/CSS, хотя index/ready/API работали. Теперь для allowlist нормализуются разделители, а исходный StaticFiles по-прежнему разрешает путь и защищает public-root. Добавлены проверки настоящих JS/CSS в Windows runtime lifecycle и frozen EXE; браузерный сценарий подтвердил исправление.

## Ограничения
Нет реального OPPO, Windows пользователя, коммерческой подписи EXE/APK, внешней LLM и межустройственной синхронизации в демо.
