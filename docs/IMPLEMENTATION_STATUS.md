# IMPLEMENTATION_STATUS — текущее состояние пилотной ветки

**Ветка:** `feat/mvp-core-bootstrap`. Основная `main` содержит согласовываемую документацию v0.2. Этот документ не заменяет `docs/SPEC-00.md`.

## Реализовано в коде (первый сквозной каркас)
- `backend/`: FastAPI, SQLAlchemy, авторизация, роли и назначения на объекты, отчёты `work` / `no_work`, client UUID + идемпотентность, фотографии SHA-256, отдельная квитанция submit, revision-конфликты, manager review, журнал правок, аналитическая сводка по сопоставимым единицам. SQLite — development; возможен DATABASE_URL PostgreSQL, но **миграции ещё не готовы**.
- `web/`: адаптивная React/Vite панель с входом, списком объектов, журналом и карточкой отчёта, простой аналитикой на реальном API; отсутствующие метрики не подделываются. Чат ИИ пока отключён.
- `android/`: Compose форма и вход, выбор объекта, несколько рабочих операций, фото, черновики в Room, очередь WorkManager, серверный receipt и видимые состояния доставки, токен через Android Keystore. Классификаторы работ временные (до SPEC-00 B07).

## Проверки
- Локально: `cd backend && PYTHONPATH=. pytest -q` → 4 passed; `python -m compileall -q app` → success.
- CI: Backend tests + Web build → PASS на GitHub Actions.
- Android assembleDebug → PASS на GitHub Actions до добавления публикации APK; повторная сборка с артефактом выполняется CI.
- Пока **НЕ ТЕСТИРОВАЛИСЬ** реальные телефоны, Windows заказчика, PostgreSQL, реальный HTTPS, резервное восстановление, E2E Android→PostgreSQL→Web.
