# ROADMAP — 14 дней (5 + 9)

План целевой, не гарантия отсутствия дефектов; требует утверждённого контракта и тестовой инфраструктуры.

| День | Фокус | Контрольный результат |
|---|---|---|
| 1 | Android: UI, формы, локальная БД; утвердить API | APK сохраняет отчёт офлайн |
| 2 | Android: WorkManager, фото, синхронизация | APK работает с контрактным тестовым API |
| 3 | FastAPI, PostgreSQL, роли, отчёты, вложения | Реальный API + миграции + тесты |
| 4 | Web: фильтры, контроль отчётности, объекты, графики | Дашборд читает серверные данные |
| 5 | ИИ-аналитик, интеграция, тестовый deploy | Первый сквозной MVP |
| 6 | E2E телефон → БД → дашборд | Все основные сценарии |
| 7 | Сеть, повторы, обязательные фото | Не теряются/не дублируются |
| 8 | Права, внешний доступ, backup/restore | Защищённый контур |
| 9 | Полевые тесты | Реальные пробные отчёты |
| 10 | Сверка KPI, ИИ-ответов, фильтров | Проверенные числа |
| 11 | UX и исправления | Критические дефекты закрыты |
| 12 | Регрессия | Стабильность после изменений |
| 13 | Windows deployment, инструкции | Релиз-кандидат |
| 14 | Приёмка | Протокол и решение о пилоте |

Контрольные точки: день 2 — APK, день 5 — интеграция, день 8 — закрыты риски доставки и доступа, день 14 — приёмка. Начиная с дня 6 — только испытания/исправления; новые функции в отдельный backlog.
