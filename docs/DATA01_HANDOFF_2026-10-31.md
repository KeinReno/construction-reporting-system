# DATA-01: состояние к передаче 31.10.2026

Реальные данные сохранены только вне Git в `B:\CRS-runtime`. Этот коммит публикует исходники, миграцию и синтетические проверки, не клиентскую БД, документы, фотографии или credentials. База и действующий локальный кабинет не являются демонстрационными fixtures.

## Реализовано

`app.normalize_import`: offline-разбор полного доступного корпуса, классификация работ, извлечение однозначных количеств/заявленных расходов/часов техники, очередь уточнений. Исходный payload отправленных отчётов, UUID, ревизии, receipt и история не переписываются. Аналитическая проекция хранится в ReportSource `_normalization`, связана с SHA-256 payload и исходного текста. При их изменении устаревшая проекция не используется. Сохраняются точные цитаты и позиции в первичке.

`imported_corpora` (миграция 0007) содержит полный доступный корпус, дубли, метаданные недоступных документов и ссылки на скопированные фото. Повторы не становятся дополнительными отчётами. База/storage восстанавливаются штатным backup/restore без исходной выгрузки. Backup теперь включает corpus-фотографии, а не только Photo.

GET `/imports/coverage`, `/imports/{id}/records`, `/imports/{id}/media/{id}` доступны manager/admin; нужен доступ ко всем объектам корпуса, пустой scope закрыт. Foreman не получает корпус. `/reports` сохраняет исходный `data` и добавляет необязательную `normalization`; Web использует её отдельно для отображения. Android-контракт исходного отчёта не менялся. Финансы нормализованной истории используют `date_basis=report_date`, когда дата оплаты отдельно не указана, с видимой подписью. Неизвестная принадлежность техники — null, не «своя». Отсутствие описания работ — not_stated, не подтверждённый простой.
