# Упрощение кабинета владельца — 03.11.2026

Владелец уточнил, что упрощать нужно кабинет получателя отчётов. Главная теперь содержит список объектов, последние отчёты с приоритетом ожидающих проверки и переходы к аналитике и деньгам. Диаграмма авторов в журнале раскрывается по запросу. Фильтры и подробные разделы сохранены. При переходе на главную сбрасывается фильтр объекта и периода, чтобы не скрывать остальные объекты.

Денежные итоги учитывают выбранный вид и категорию; некорректный период не показывает пустую сводку. Аналитика поясняет исключение возвращённых отчётов; денежный журнал поясняет их включение. API и структура базы не менялись. Интерфейс сотрудника не изменялся.

Проверка проводилась на синтетическом API. Независимый QA проверил путь объект — отчёт — назад, принятие, возврат с причиной, конфликт 409, раскрытие авторов, аналитику, деньги и вёрстку на 320/390 и desktop. Фото и физический телефон не проверялись. Снимки — B:/Temp/crs-owner-qa-desktop.png, crs-owner-qa-390.png, crs-owner-qa-320.png.

При локальной проверке API с учётной записью руководителя вернул 94 отчёта; это не сверка полноты переноса и не приёмка заказчиком. Часть прежних E2E привязана к удалённому оформлению главной и должна быть обновлена; полный старый набор не объявляется пройденным.
