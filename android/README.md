# Android — offline-first

Compose + Room + WorkManager. Формы `work`/`no_work`, несколько работ, фото, очередь, receipt, авторская привязка локальных данных, кэш объектов, возврат и исправление отчётов. Транспорт и бизнес-статус показываются отдельно.

```bash
cd android
gradle :app:testDebugUnitTest :app:assembleDebug -PapiBaseUrl=https://example.org/api/v1
```
Требуются JDK 17, Gradle 8.13, Android SDK 35. Указать реальный согласованный HTTPS endpoint; стандартный example.invalid не подключается к серверу. APK GitHub Actions — debug, не подписанный производственный релиз. Gradle установлен CI, wrapper пока отсутствует.

Тесты проверяют retry-классификацию, сравнение payload и независимую от UI машину отправки: повторные исправления после ошибки фото, потерю PATCH/submit-response и защиту от изменения серверного документа. Они не заменяют Room/WorkManager instrumented tests и испытание OPPO Reno8 5G.

После первого успешного входа объекты кэшируются для офлайн-формы. Сохранение подтверждается только после Room commit. После истечения токена войти заново и нажать «Повторить отправку». Постоянные ошибки требуют проверки; отклонённый локальный отчёт можно исправить. Для возвращённого сервером отчёта нажать «Проверить статус / исправить», внести правки с причиной и отправить новую revision.

Room 1→2→3 сохраняет данные. Старые записи без владельца не отправляются и не видны новому аккаунту; восстановление только с подтверждением исходного владельца. Старая сессия требует повторного входа. Unsent форма до нажатия сохранения ещё не имеет гарантии пережить завершение процесса; автоматическое сохранение незавершённой формы и cleanup orphan-фото остаются задачами UX.

Справочники временные до B07; материалы, состав, времена, финансы и инциденты заблокированы SPEC-00. Реальный телефон/полевые сети пока NOT_TESTED.
