# Android prototype — offline-first

Приложение бригадира на Kotlin/Compose + Room + WorkManager. Вход, выбор объекта, дата, режим «выполнены работы / нет работ», несколько рабочих операций, необязательный комментарий, фото, локальная очередь, автоотправка, подтверждение серверной квитанции и история статусов. Токен защищён Android Keystore. API URL обязателен по HTTPS. **Неподтверждённые справочники пока временные** — заменить API после SPEC-00.

## Сборка
Требуются Android SDK 35, JDK 17, Gradle 8.13. Пример:
```
cd android
gradle :app:assembleDebug -PapiBaseUrl=https://example.org/api/v1
```
Адрес example.org — пример, нужно использовать доступный HTTPS API заказчика; настоящие URL/секреты в Git не помещать. Gradle wrapper будет добавлен после первой проверки CI. Репозиторий не содержит клиентских данных.

## Известные ограничения
- Android SDK локально в окружении разработчика отсутствует; реальную сборку проверяет GitHub Actions, тестирование на OPPO Reno8 5G ещё не выполнено.
- Полноправные справочники материалов/инцидентов, состав бригады, финансовые поля, возможности ручного исправления возвращённых отчётов требуют финализации SPEC-00 и API.
- При истечении сессии повторная отправка потребует нового входа. Не предназначено для эксплуатации до проверки защиты данных и сетевых сценариев.
