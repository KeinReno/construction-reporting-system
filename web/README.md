# Web — рабочая начальная панель руководителя

Разработана на React/TypeScript/Vite. Включены вход, список разрешённых объектов, журнал отчётов, детализация работ, сводные данные сервера, фильтры и адаптивный интерфейс. **Никаких демонстрационных цифр, выдаваемых за реальные:** график отсутствующей отчётности, инциденты и ИИ явно помечены как неподключённые до соответствующих API и решений SPEC-00.

## Запуск в разработке
```
cd web
npm install
npm run dev
```
Vite проксирует `/api` к `http://127.0.0.1:8000` (позже конфигурация). Запустить FastAPI отдельно. Основные сценарии будут интегрированы после согласования контрактов. Серверные токены не сохраняются в localStorage/sessionStorage, остаются только в памяти вкладки.

Не предназначено для эксплуатации до SSL reverse-proxy, проверки прав, сборки CI, тестирования на iPhone и ограничений пользовательских сессий.
