# Construction Reporting System

**Статус: технический MVP в draft PR #2; согласование SPEC-00 не завершено.** Техническое ядро Android/API/Web, администрирование, ручной импорт и Windows runtime реализованы; приёмка и расширенная бизнес-модель не завершены. [Поставка и оставшиеся входные данные](docs/RELEASE_HANDOFF.md). [Точный статус](docs/IMPLEMENTATION_STATUS.md), [проверки](docs/QA_RELEASE_2026-10-26.md). Репозиторий: отдельная строительная система, не часть KAIDEN Orion.

## Цель
3–4 ответственных отправителя, несколько объектов, ориентировочно 10–20 отчётов ежедневно. Android формирует стандартизированные сменные отчёты, Windows-сервер хранит их в PostgreSQL и закрытом файловом хранилище, адаптивный Web показывает объекты/дисциплину/аналитику, необязательный ИИ объясняет **проверяемые** показатели. Основные данные — структурированные; свободный комментарий необязателен.

**График:** SPEC-00 до начала отсчёта; разработка дни 1–5 (Android 1–2, Backend 3, Web 4, интеграция + минимальный ИИ 5); испытания/исправления дни 6–14. Даты условные, завершение определяется приёмкой.

## Стек и директории
- `android/` — Kotlin / Jetpack Compose / Room / WorkManager.
- `backend/` — Python FastAPI + PostgreSQL + миграции + приватные вложения.
- `web/` — React / TypeScript / Vite, адаптивный интерфейс.
- `docs/` — единый источник контрактов, критериев и открытых решений.

## Безопасность
Репозиторий **пока публичный**. **Никогда не коммитить** клиентские фото, переписки, чеки, ФИО, телефонные номера, адреса объектов, IP, ключи, пароли и прочие внутренние данные. Примеры только вымышленные и обезличенные; реальные данные используются исключительно в отдельном защищённом окружении. Переход в Private рекомендуется до любой работы с материалами клиента.

## Что не обещаем в MVP
Автоматический импорт истории MAX, полноценную бухгалтерию, прогнозирование, управление задачами, онлайн-работу при недоступном Windows-сервере, интеграцию с Orion и достоверное измерение объёмов по фотографиям.
