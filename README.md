# Construction Reporting System

Самостоятельная система оперативной строительной отчётности: Android-приложение сотрудников, Windows-сервер с PostgreSQL и FastAPI, адаптивный веб-дашборд руководителя и ограниченный ИИ-аналитик.

**Статус:** подготовка MVP; код приложения ещё не написан.
**План:** 5 дней разработки + 9 дней испытаний и корректировок.

## Назначение
- Несколько объектов и 3–4 отправителя, примерно 10–20 ежедневных отчётов.
- Основные сведения вводятся в обязательные структурированные поля, а не свободным сообщением.
- Дополнительный комментарий разрешён, но не заменяет обязательные данные.
- Фото имеют проверяемые связи с отчётом, видами работ и инцидентами.
- Android надёжно сохраняет отчёты офлайн и синхронизирует их после восстановления сети.
- Windows-сервер заказчика хранит данные; веб-дашборд работает на ПК, iPhone и Android.
- ИИ только анализирует подтверждённые серверные данные; числовые расчёты выполняет сервер.
- Будущая интеграция с KAIDEN Orion через версионированное API, без зависимости в MVP.

## Компоненты
- android/ — Kotlin, Jetpack Compose, Room, WorkManager
- backend/ — FastAPI, PostgreSQL, миграции и файловое хранилище
- web/ — React, TypeScript, Vite, визуализация
- docs/ — требования, контракты, план, приёмка и инструкции
