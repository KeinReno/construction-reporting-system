## Результат

Финальная регрессия: **27/27 проверок PASS** в check.cjs; **2/2 PASS** в money.cjs. Заполненный Web-отчёт дополнительно проверен на ширинах 1440/390/320. 21 снимок в qa/screenshots. Все команды завершились с кодом 0.

- Шесть экранов × 1440/390/320: горизонтального переполнения нет.
- Ввод сохраняется после перезагрузки.
- no_work требует причину; валидная причина позволяет продолжить без фиктивного объёма.
- Начальная очередь скрывает недоставленный отчёт от заказчика; восстановление связи доставляет его.
- Отправка → возврат → локальное исправление → повторная отправка → версия 2 → принятие: проходит.
- Локальное исправление не подменяет ранее доставленный текст Web-отчёта; принятый отчёт недоступен для редактирования.
- Сумма с запятой корректно отображается при прямом переходе в предпросмотр; нечисловая сумма отображает подсказку и блокируется при отправке.
- Ошибок JavaScript в основном прогоне нет.

## Найдено и исправлено разработчиком

**P1 — локальная правка подменяла доставленный отчёт.** Шаги: отправить no_work с причиной → вернуть с уточнением → изменить причину в аапп → открыть Web-отчёт без повторной отправки. Ожидалось: исходная доставленная причина. Фактически: неотправленный текст черновика. Разработчик разделил доставленный снимок и локальный ввод. Независимая регрессия PASS.

**P2 — отображение суммы с запятой при обходе кнопки проверки.** Из анализа кода обнаружен риск Number('4800,50') → NaN при прямом переходе в предпросмотр. Разработчик нормализовал отображение и добавил подсказку для незаконченного ввода. Независимые сценарии после исправления PASS. До исправления отдельного браузерного воспроизведения этого дефекта не выполнялось.
